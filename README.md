Short Reflection
What functions did you create in your calculator program?

I made four main functions to handle the math operations: add_numbers, subtract_numbers, multiply_numbers, and divide_numbers.

What parameters did your functions use?

Each function used two parameters (num1 and num2) as placeholders to receive the two numbers input by the user.

What arguments were passed when the functions were called?

I passed first_num and second_num—the actual numbers typed in by the user—into the functions as arguments when calling them.

How did your program use the returned value?

Once a function calculated the answer, it returned the value back to the main program. I stored that output in a variable called result and printed it out so the user could see the final answer.

Why is it better to divide the calculator program into functions instead of writing everything in one long block of code?

Breaking the program into functions makes the code a lot cleaner and easier to read. Instead of crowding everything into one big block, each task has its own job. It also makes fixing bugs much easier—for instance, if something goes wrong with division, I only have to check the divide_numbers function without messing up the rest of the code.
